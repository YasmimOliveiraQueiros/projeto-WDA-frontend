# projeto-WDA-frontend

Repositório frontend do projeto WDA, criado como atividade prática de configuração de repositório com histórico de commits seguindo o fluxo GitFlow.

## Estrutura de Branches

- `main` → versão estável e pronta para produção
- `develop` → branch de desenvolvimento, integra novas funcionalidades

## Como clonar o repositório

git clone https://github.com/YasmimOliveiraQueiros/projeto-WDA-frontend.git
cd projeto-WDA-frontend

## Status

Projeto em desenvolvimento inicial.
